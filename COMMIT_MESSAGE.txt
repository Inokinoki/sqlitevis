Improve VDBE, Parse, and B-tree visualization

This commit significantly improves the three main visualization systems
in SQLiteVis as part of Ralph Loop Iteration 1.

VDBE Visualization:
- Store all opcodes in an array instead of overwriting
- Track current program counter position
- Replace drawVdbeOpcode/drawVdbeState with unified drawVdbeList
- Display complete program with current instruction highlighted
- Show program state (starting, executing, complete) and instruction count

Parse Tree Visualization:
- Add comprehensive tokenTypeNames mapping (127 SQLite token types)
- Convert numeric token types to human-readable names
- Example: 38 → "TK_SELECT", 41 → "TK_FROM"

B-Tree Page Visualization:
- Enhance addPage() to accept optional parentPage parameter
- Track lastAccessedPage for establishing context
- Update splitPage() to create proper sibling relationships
- Automatically maintain parent-child bidirectional links

All changes are backward compatible with existing event handlers
and WASM instrumentation.
