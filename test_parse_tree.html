🌳 Parse Tree Visualization Test

Instructions:
  1. Select "SQL Parse Tree" from the View dropdown
  2. Click one of the SQL examples below or type your own
  3. Click "Execute SQL" to see the parse tree
  4. The visualization will show the SQL structure as a tree with color-coded nodes

Quick Test SQL

Expected Visualization

The parse tree should show:

  • SQL Query - displayed at the top
  • Tree Nodes - circular nodes representing SQL structure
  • Node Colors:
    • Purple - Command keywords (SELECT, INSERT, etc.)
    • Green - Identifiers (table names, column names)
    • Blue - Other elements
  • Connections - lines showing parent-child relationships
  • Tokens - list of parsed tokens at the bottom (if events are available)

Test Different View Modes

Switch between view modes to see different visualizations:

  • B-Tree Structure - Shows page-based storage structure
  • SQL Parse Tree - Shows SQL query structure (NEW!)
  • VDBE Execution - Shows virtual machine execution
